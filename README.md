# Student Management System

A Python-based Student Management System designed to manage student records through a simple graphical user interface.

## Features
- Add student details
- View all student records
- Search students
- Update student information
- Delete student records
- Store student data using SQLite
- Calculate and display student performance
- Pass/Fail status based on marks

## Technologies Used
- Python
- Tkinter
- SQLite

## Database
The project uses SQLite to store and manage student information securely in a local database.

## Purpose
This project was created to practice Python programming, GUI development, database management, and CRUD operations.

2. Open the terminal.
